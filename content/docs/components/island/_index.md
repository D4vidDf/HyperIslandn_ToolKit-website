# Dynamic Island Configuration

This section covers the components specifically designed for the **Dynamic Island** (popup) behavior. Unlike the standard notification card, these components control what happens when the notification appears as a capsule or expands.

## Available Modules

| Module | Class | Description |
| :--- | :--- | :--- |
| **Configuration** | `ParamIsland` | Global settings (priority, timeout, dismiss behavior). |
| **Small Island** | `SmallIslandArea` | The layout when the island is in its compact state. |
| **Big Island** | `BigIslandArea` | The layout when the island is expanded (long-press). |
