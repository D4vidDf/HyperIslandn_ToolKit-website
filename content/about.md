**HyperIsland ToolKit** is an open-source Kotlin library dedicated to simplifying the development of Dynamic HyperIsland notifications (Focus Notifications) for Xiaomi HyperOS.

## The Mission

Implementing system-level features often involves undocumented APIs and complex data structures. Our mission is to wrapper these complexities into a clean, type-safe, and documented Developer Experience (DX).

We believe that creating beautiful, native-feeling notifications shouldn't require reverse-engineering system JSON payloads.

## Key Features

* **Type Safety:** Built with Kotlin DSL to prevent runtime errors.
* **Zero Boilerplate:** Hides the complexity of `miui.focus` extras and Bundles.
* **Up-to-Date:** Continuously updated to support the latest HyperOS templates.
